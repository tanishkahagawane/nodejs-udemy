What is Node.js?

- A javascript runtime
- it allows to run javascript not just in browser but anywhere else like a normal programming language.

How does it work?

- Node.js uses v8 engine
- v8 is a javascript engine bulit by google that runs javascript in the browser.
- Engine takes js code and then compiles to machine code which runs on computer
- v8 is written in c++

- node js takes v8 code bases and adds certain features like
  example -
  1.working with local files. 2.opening files ,reading , deleting files

- node - to get interactive mode
- node -v
- node first-app.js
